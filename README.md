# Smarties-holder

# What it is

This is a small Smarties holder. It has a thread on one side to keep it closed. It also has paracord to tie it to the bag or a round ur hand.

# Why I made

The reason I made this was that I love Smarties. But the plastic wrapper only held so much, so this is a bigger and stronger holder that u can attach to ur bag.
